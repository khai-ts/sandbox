# Fairplate (working name)

A people-owned, low-fee food delivery network: open source, federated by city, and
governed as a multi-stakeholder cooperative of drivers, shops and customers.

- **Shops** pay 0% commission.
- **Drivers** keep 100% of delivery fees and tips, and set their own minimums.
- **Customers** pay a flat, transparent network fee.
- **Software** is maintained mostly by Claude Code under human governance.

See [docs/PLAN.md](docs/PLAN.md) for the full plan.
